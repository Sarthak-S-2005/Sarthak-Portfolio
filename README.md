**Technologies:** Python, PyTorch, Real-ESRGAN, Streamlit.

### 2. Campus-Voice — Campus Announcement Platform

A web-based campus announcement platform designed to improve communication between administrators, departments and students.

- Role-based access for Admin, Department and Student users.
- Announcement management and filtering.
- Comments and notifications.
- Flask backend with MongoDB integration.

**Technologies:** Python, Flask, MongoDB, HTML, CSS, JavaScript.

🔗 [View GitHub Repository](https://github.com/Sarthak-S-2005/Campus-Voice)

### 3. Student Performance Predictor

A machine learning application that predicts student academic performance using inputs such as study hours and attendance.

- Uses Linear Regression for score prediction.
- Provides a web-based interface.
- Includes prediction visualizations and history.

**Technologies:** Python, Scikit-learn, Flask, Streamlit, SQLite, Pandas, Matplotlib.

🔗 [View GitHub Repository](https://github.com/Sarthak-S-2005/student-performance-predictor)

### 4. Stress Level Detection using Machine Learning & Image Processing

A computer vision-based prototype that explores facial features for estimating stress levels.

- Webcam-based facial input.
- Face detection and image preprocessing.
- Facial feature extraction.
- Machine learning-based stress classification.
- Dashboard, stress history and trend visualization.
- Guided breathing exercises.

**Technologies:** Python, Flask, OpenCV, NumPy, Scikit-learn, Joblib, Chart.js.
